# Momo · 默默

给求职路上的情绪，一小块留白。一个无需注册的情绪日记与自我关怀静态原型：先留下一句想法，愿意时再主动问 AI；不想分析，也可以呼吸、听一点声音或走几步。

桌面网页以一台可操作的 iPhone 为中心，两侧与下方呈现创作者的用户理解、研究流程和设计取舍；手机网页保留完整体验。

## 打开体验

直接用现代浏览器打开 [`index.html`](index.html)，不需要安装依赖、登录或配置 API 密钥。启用 JavaScript 后即可操作手机里的按钮与卡片。

也可以在项目根目录启动本地静态服务器，让浏览器本地存储有稳定的访问地址：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

随后访问 [本地原型](http://127.0.0.1:8000)。不要使用浏览器隐私模式测试长期保存；不同浏览器、端口、`localhost` / `127.0.0.1` 或直接打开文件，会使用不同的本地存储空间。

## 建议体验顺序

1. 初次进入时是一张可直接书写的空白想法主卡，左下方露出两张重叠的卡片背面，不展示预置日记的文字或情绪。可直接输入 1–50 字，简短操作提示随时可关闭，可以选情绪，也可以留空，再保存。
2. 从空白卡向左滑，或点“更早的想法”，主动查看历史与示例；向右滑回到较新记录，在最新位置继续右滑回到空白卡。鼠标可用下方按钮，键盘聚焦卡片区后可用左右方向键。保存后显示刚写的卡片；已有个人记录时再次访问，先显示自己的最新记录。
3. 点预置卡片上的“问 AI”，查看澄清问题、触发因素和下一步建议；点建议按钮继续看预设内容。七张示例卡片都有对应对话。
4. 在自己的新卡片上点“问 AI”，会看到静态原型说明，可以转到案例列表，也可以回到自己的记录。
5. 点右上角“⋯”，切换为“只记录”；AI 入口会隐藏。再次打开同一菜单可以恢复，选择保存在当前浏览器。
6. 点顶栏的回看图标，在“我的记录”和“示例记录”之间切换。查看日期与情绪时间点、打开具体想法；底部可以导出或清除个人记录。
7. 点“照顾自己”，体验 1 分钟呼吸、2 分钟音景或 5 分钟走动。每项都可以开始、暂停、继续或提前结束。音景由浏览器本地合成，点击开始后才会播放，可调节音量。

## 能力与数据边界

- **真实可用的交互：** 卡片翻阅、创建短记录、可选情绪、字数校验、本地草稿与保存、只记录偏好、情绪回看、JSON 导出、确认清除、呼吸与活动计时、实际音频播放及停止。
- **预设演示：** AI 的追问、用户回复、触发因素和建议。没有接入真实模型，不会针对新笔记生成回答，也不会发送用户输入；对话中的输入外观按钮会解释这一限制。
- **外部信息：** 未连接小红书、抖音或其他平台，不提供虚构检索结果、公司评价或维权结论。联网信息参考与长事实记录属于后续范围。
- **日记保存：** 内容与草稿保存在当前浏览器，不自动同步、不上传到服务器。浏览器清除数据、无痕模式结束或更换访问地址都可能使原有记录不可见。共用设备的人可能看到记录；此原型没有设备锁或加密功能。
- **导出 / 清除：** 导出只包含已保存的个人日记、日期和情绪，不包含示例、草稿、偏好或练习反馈。清除前需再次确认，会删除当前浏览器的个人笔记和草稿，保留示例与模式偏好；不提供导入和撤销。
- **练习反馈：** 结束后的“松一点了 / 差不多 / 更紧绷了”仅用于本次反馈，不写入日记、不长期保存、不统计练习次数或疗效。
- **研究边界：** 两份 Atypica 报告来自 AI 角色研究，作为设计假设与风险提示；不包装成真人访谈、临床研究或已经证实的产品效果。研究过程与原始链接见来源核验文档。

声音需要支持 Web Audio 的现代浏览器，并由用户点击启动。若浏览器不支持或阻止音频，界面会提示，可继续使用其他练习。所有练习面向日常自我关怀，不是诊断、治疗或危机支持服务。

## 文件与维护

```text
index.html                 桌面展示与产品入口
styles/main.css            网页、设备和产品布局
scripts/ios-frame.js        iPhone 外观与内容容器
scripts/data.js             编写的示例日记与对话
scripts/app.js              日记、回看、偏好、导出与清除
scripts/care.js             三类练习、计时与本地音频
docs/                      洞察报告、PRD、来源记录
prototypes.html             七张原型图总览
prototypes/                真实界面截图
assets/                    图标与设计参考
```

文档网页由 Markdown 生成。修改两份 `.md` 后，在项目根目录运行：

```sh
python3 docs/build_docs.py
```

交付的 HTML 已生成，阅读无需运行此命令。文档页面也提供 Markdown 下载，并支持浏览器打印。

评审时可以通过 `?screen=write`、`?screen=chat`、`?screen=review`、`?screen=care` 直接打开对应界面；`?screen=chat&detail=1` 直接展示建议。`?embed=1` 是用于干净预览 / 截图的独立演示模式，不读取或持久保存个人数据。日常体验与保存请使用普通 `index.html`。

## 复核清单

以下是可重复的交付验收步骤，不是用户研究结论：

- 桌面与手机窄屏能完整打开，文档、原型图与返回链接可达。
- 没有个人记录时首页是一张可输入的空白主卡与左下方两张无内容卡背，不露出示例内容；主动翻阅才进入历史，返回空白卡保留未保存草稿。
- 新建中文及组合表情记录，空白 / 超限时不能保存，合规输入可保存；刷新后核对笔记、草稿与只记录偏好。
- 连续翻阅七张示例及个人记录，当前与左右可见总数始终不超过五张，首尾没有死路。
- 每张示例打开对应对话；自己的新记录进入明确的静态边界提示；只记录状态隐藏 AI 入口且可恢复。
- 回看将个人与示例分开，不自动推断情绪，不绘制高低评分曲线。
- 三种练习能启动、暂停、恢复和提前结束；音景能实际播放、调音量，并在离开后停止。
- 导出 JSON 仅包含个人记录；取消清除不影响数据，确认清除后刷新核对；示例继续可用。
- 目录与定位 / 风险锚点有效；七张原型图与实际界面一致。

本轮验证聚焦界面与功能行为，不代替真人可用性测试、长期使用研究或 AI 输出质量评估。

实际完成的检查与浏览器验证范围见 [`docs/验收记录.md`](docs/验收记录.md)。
