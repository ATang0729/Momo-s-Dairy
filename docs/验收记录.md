## 关键行为验证

- 新记录即时置于当前卡片；记录与草稿使用本地存储，刷新后笔记内容与选择的情绪保留。
- 初访提示可关闭，偏好菜单可以查看完整操作说明。
- 只记录模式隐藏卡片 AI 入口，同时保留记录、翻阅和自助练习。
- 个人回看与示例回看分开；未选择情绪的内容不会被自动推断情绪。
- 1 分钟呼吸：从 01:00 正常减少至 00:39，暂停后可继续，也能提前结束并跳过感受标记。
- 2 分钟音景：由开始按钮触发 Web Audio 播放路径，出现暂停状态，音量从25%调整至26%；暂停与返回正常，无运行错误。音源为本地噪声滤波与轻柔音调，不是外部音乐平台。
- 5 分钟走动：实际开始至05:00活动状态，步骤说明出现，可暂停或提前结束。
- 模块另经独立 Node VM 行为检查：时间戳抗漂移、自然结束、音频异步取消和资源清理。真实浏览器验证没有等待满5分钟；不据此声称做过完整时长听感评测。
- 从练习页打开PRD再后退，产品正常重新加载到主页，没有空白设备；代码另含页面缓存恢复时重建练习菜单的处理。
- 本次创建的测试记录已通过界面清除，没有混进示例与交付图。
- JavaScript语法检查全部通过；演示数据7条均不超过50个完整字形，且每条都有完整对应对话。
- 四个HTML页面共98个本地链接/资源/锚点通过检查。动态创建的 `#phone-app` 在实际浏览器中确认。
- 七张JPEG均通过图像完整性检查；原型图集所有图片加载、放大层与键盘Esc关闭实际通过。
- 主产品浏览器错误日志为0。

## 验证边界

本地 HTTP 服务已实际运行并验收。内置浏览器限制 `file://` 协议，因此没有通过该自动化浏览器验证直接双击HTML；交付使用普通经典脚本和相对路径，不依赖CDN、构建或后端，推荐按README启动本地静态服务。

JSON导出按钮与Blob生成路径已检查，浏览器中已触发导出；自动化下载事件没有返回文件句柄，因此没有核验下载文件落盘内容。清除前提示、确认清除及清除后的空态已实际检查。

本次未接入真实模型、用户体系、云同步、跨平台检索、真实求职数据或心理诊断。练习后的感受选择仅是当次反馈，不长期保存。未进行真人可用性测试、长期情绪影响研究或临床效果验证。

- 新用户默认显示一张可直接输入的空白主卡，左下方露出两张重叠卡背，DOM 中没有示例日记文字或 AI 按钮；不在背面露出示例情绪。
